# Character animation assets

`idle.fbx` and `walking.fbx` are the idle and walk clips used by the character configurator project. They are loaded only by the lazy Explore route and retargeted to `assets/models/Kate.vrm` at runtime.

Source project: https://github.com/Janson2025/r3f-ultimate-character-configurator
Live asset host: https://r3f-ultimate-character-configurator-ten.vercel.app/animations/
